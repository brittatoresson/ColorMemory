# ColorMemory
### Uppgiften är att konstruera ett spel som kallas ”Colour Memory”. 

* Spelplanen ska bestå av ett 4x4 rutnät, 16 rutor totalt.
* Alla kortplatser består av nedåtvända kort.
* Spelet går ut på att vända två kort (ett kort i taget) och försöka hitta två kort med samma färg.
### Regler
* Om två kort är lika, får spelaren ett poäng, och korten tas bort från spelplanen efter två sekunder. (Under denna tid ska spelaren inte kunna välja ett nytt kort.)
* Om korten inte är lika förlorar spelaren ett poäng och korten vänds nedåt igen efter två sekunder. Detta fortsätter tills alla paren har hittats.
### Features  
* Spelet ska visa information om aktuell spelomgång, exempelvis ”Poäng just nu”. Var kreativ.
* Du får själv komma på ett sätt att visa vilket kort som är markerat.
* När spelet är över, ska spelaren meddelas detta.
* Spelaren ska ha möjlighet att starta en ny spelomgång.
